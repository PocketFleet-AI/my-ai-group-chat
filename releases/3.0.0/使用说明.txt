=========================================================
PocketFleet 使用说明（Windows纯净版，适配Win10/Win11）
==================================================

这个工具可以将你已有的多个AI组成协作小组：沿用你自己的AI账号，在Telegram群组发起AI会议，AI自动分工、执行任务、交叉复核，最终交付结果。

--------------------------------------------------
第一步：双击 PocketFleet.exe 没反应？
--------------------------------------------------
Win10系统缺少 WebView2 运行组件，需要手动安装（微软官方免费，约1.5MB）：
下载地址：https://developer.microsoft.com/zh-cn/microsoft-edge/webview2/
选择「Evergreen 引导程序」安装，完成后重新打开 PocketFleet.exe。
✅ Win11自带该组件，可以直接跳过这一步。

--------------------------------------------------
第二步：创建 Telegram Bot（必做）
--------------------------------------------------
1. Telegram搜索 @BotFather 并打开对话
2. 发送指令 /newbot，按提示设置机器人名称、用户名（用户名必须以bot结尾，例如：my_assistant_bot）
3. 复制BotFather返回的Token，格式类似：123456789:AAxxxxxx
4. 回到 PocketFleet，把Token粘贴进去；出现绿色【已验证】、自动显示机器人名字，代表成功
5. 至少配置2个Bot，底部状态条全部变绿，再进入下一步

--------------------------------------------------
第三步：安装浏览器插件（网页 AI 必需）
--------------------------------------------------
要连接 ChatGPT、Claude、Gemini、DeepSeek 等网页 AI，需要安装 PocketFleet Web Bridge 浏览器插件。

方式 A【推荐：Chrome 官方应用商店】
1. 在 PocketFleet 客户端点击「🏪 商店页面」。
2. 在 Chrome 应用商店点击「添加至 Chrome」。
3. 回到 PocketFleet，点击「🔑 复制配对码」。
4. 打开浏览器右上角的 PocketFleet 插件弹窗。
5. 在 Connection Settings 中粘贴配对码，点击 Save。
6. 插件显示 Connected / Connection normal，即表示本地网桥已连接。
商店版本由 Chrome 自动管理更新，适合绝大多数用户。

方式 B【备用：本地加载插件】
如果无法访问 Chrome 应用商店，或需要使用与当前桌面程序配套的插件版本：
1. 在 PocketFleet 点击「📂 打开插件目录」。
2. 打开 Chrome，输入 chrome://extensions 并回车。
3. 开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择解压目录中的 browser-extension 文件夹。
配套本地插件支持自动配对，通常无需手动输入配对码。
注意：本地加载版本不会通过 Chrome 应用商店自动更新。

安全提醒：配对码是本机内部通信凭据，不要公开分享。
仅使用本地 IDE/CLI 代码 AI 的用户，可跳过浏览器插件安装。

--------------------------------------------------
第四步：接入Telegram群组（必做）
--------------------------------------------------
1. 用你自己的Telegram账号新建群组，把刚才建好的Bot拉进群，并设为管理员
2. 在群组内发送指令：/PocketFleet
3. 自检列表4项全部打绿，就可以发起AI会议了

--------------------------------------------------
第五步：接入网页版AI 或 工具（代码）类AI（至少接入一类，二选一）
--------------------------------------------------
你至少要接入其中一类AI，才能发起会议：
- 网页类AI：由上面浏览器插件链路完成接入，如：ChatGPT、Claude、Gemini、Grok、Deepseek等。
- 工具（代码）类AI：如CodeX、Claude Code、Cursor、GitHub Copilot、Antigravity、WorkBuddy、Deepseek Harness等
  - IDE方式：安装对应官方IDE，上手简单；缺点是AI交互时会抢占窗口焦点
  - CLI方式：安装对应官方CLI，需要在命令行完成鉴权，上手门槛略高；优势是后台静默运行，不会抢占窗口

⚠️ 注意：这类IDE/CLI工具需要你自行提前安装、登录好自己账号。
PocketFleet不会帮你安装，也不会取用你的账号。

--------------------------------------------------
故障排查位置
--------------------------------------------------
程序日志：%APPDATA%\PocketFleet\debug.log
直接复制这条路径粘贴到文件管理器地址栏，就能打开日志。

你的所有配置文件：%APPDATA%\PocketFleet\pocketfleet.json
配置独立保存在用户目录，移动exe不会丢失；重装系统前可以备份这个文件。

--------------------------------------------------
高级注意事项（仅给手动修改文件的用户）
--------------------------------------------------
不要单独移动 PocketFleet.exe！
程序和 browser-extension 文件夹必须放在同一个目录。
单独剪切exe会导致插件配对失败，提示 pairing files unavailable。
